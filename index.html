An Automated Deep Learning Pipeline for Robot Code Generation from CAD Models

Giovanni Indino, Aidin Latifi, Marco Faroni, Andrea Maria Zanchettin, Paolo Rocco
8th International Conference on Industry of the Future and Smart Manufacturing (Procedia Computer Science, Elsevier)

Presents an end-to-end deep learning pipeline translating native B-rep CAD files directly into executable manufacturing robot instructions. It combines an adapted BRepNet graph neural network for edge feature extraction with a multi-modal encoder-decoder transformer and a deterministic "Snapper" post-processor to achieve sub-millimeter precision on industrial laser-cutting workflows.
